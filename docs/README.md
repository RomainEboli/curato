# Documentation personnelle — Curato

Ce dossier contient mes repères pratiques pour développer Curato et mes futurs projets.

Objectif : ne pas devoir tout retenir par cœur. Je dois pouvoir identifier un besoin, ouvrir la bonne fiche, adapter un patron existant, tester puis enregistrer mon travail avec Git.

## Méthode de travail

1. Décrire le comportement voulu en une phrase.
2. Identifier le sujet : React, TypeScript, CSS, Git ou Vite.
3. Chercher un exemple similaire dans Curato.
4. Consulter la fiche correspondante dans `docs/playbook`.
5. Adapter le code, sans modifier plusieurs choses au hasard.
6. Tester dans le navigateur et lire les erreurs.
7. Noter une erreur ou une solution utile dans le journal de bugs.
8. Faire un commit clair lorsque la fonctionnalité est validée.
